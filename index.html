• HomeWizard P1: Öppna HomeWizard Energy-appen → Inställningar → Mätare → välj din P1-mätare och slå på Lokalt API (Local API). IP-adressen hittar du i samma meny eller i din router.
• Viktigt vid körning via GitHub Pages (HTTPS): Eftersom GitHub använder krypterad https:// och HomeWizard svarar lokalt över okrypterad http:// kan webbläsaren blockera anropet av säkerhetsskäl ("Mixed Content"). Lös det genom att antingen tillåta Osäkert innehåll (Insecure content) för sidan i webbläsarens webbplatsinställningar, eller ladda ner denna index.html och öppna den direkt från datorn/mobilen hemma.
• Ngenic API: Logga in på developer.ngenic.se med ditt Ngenic-konto och skapa en personlig API-token för att hämta temperaturer och styrstatus.
